Notifications · Saved · Settings

알림 인박스, 저장된 필터/컬렉션, 앱 설정 군. users/{uid}/notifications Firestore listener (real-time), users/{uid}/savedFilters + collections + favorites 분리. 설정은 외부 link + system preferences.

Working

  • 알림 카테고리 칩 — 모두/좋아요/댓글/다운로드/팔로우/시스템 6 type.
  • 방해 금지 시간대 (DND) 설정 — Phase 4 retention 고려.
  • 4-photo 모자이크 컬렉션 커버 — visual scan 빠름.

Gaps

  • "모두 읽음 처리" 가 destructive 인데 confirm/undo 없음.
  • 계정 삭제 시 핸들 재입력 필요 — UX 마찰. "DELETE" 입력으로 단순화 가능.
  • Saved Filters 의 swipe-to-delete 외에 multi-select 모드 없음.
