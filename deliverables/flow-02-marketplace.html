Marketplace · Search · Filter Detail

코어 디스커버리 플로우. MarketplaceScreen.swift 가 트렌딩/카테고리/신규 그리드/큐레이션을 한 화면에 묶고, FilterDetailLoaderScreen → FilterDetailScreen 으로 진입. 다운로드 후 FilterAfterDownloadScreen 으로 카메라 진입을 제안.

Working

  • Marketplace 헤더 search-bar 가 실제 input 이 아닌 navigation pseudo-link — 검색 화면 phase 분리에 적합.
  • Trending 캐러셀의 첫번째 카드가 isHighlighted 로 약간 큼 — visual hierarchy 명확.
  • Pull-to-refresh 텔레메트리까지 hooked up.

Gaps

  • FilterDetail 가격 표기가 코인 아이콘 + 숫자만 — 원화 환산 (≈₩980) 보조 표기 없음.
  • 다운로드 진행률 화면에 실제 % 텍스트가 없음 — 진행 바만으로는 시간 감각 어려움.
  • 카테고리 chip 의 selected 상태가 chip 내부에 색상만 — 모션 (scale/fade) 없음.
