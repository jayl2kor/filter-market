Camera & Photo

중앙 셔터 탭으로 진입하는 fullScreenCover. 카메라 라이브 프리뷰는 OLED 다크 (이 앱에서 유일하게 다크 모드인 화면). CameraSession + MetalPreviewRenderer 가 60fps LUT 적용 라이브 프리뷰를 그립니다.

Working

  • Dark camera, light app — Apple Camera 와 동일한 패턴. OLED 절약 + 사진에 집중.
  • Filter strip 의 active 필터에 골드 외곽선 — 명확.
  • Long-press 원본 비교 — Photo Edit 에서 매우 자연스러움.

Gaps

  • 유료 필터 진입 — 카메라에서 paid filter 탭 시 paywall 모달이 라이브 프리뷰 위에 떠서 흐름 끊김.
  • Filter strip 정렬 / 핀 기능 없음 — 사용자가 필터 100+ 다운로드 시 스크롤 지옥.
  • Capture Preview 의 "사진 정보" 버튼 동작 미정의.
