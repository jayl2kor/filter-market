# moodit · 페르소나

> 1차/2차 타겟 페르소나. 디자인·기획·메시지 결정 시 "이 사람의 어떤 일을 푸는가?"로 환원하기 위한 단일 진실원.

---

## P1 — 콘텐츠 크리에이터 "지수" (1차)

| 항목 | 내용 |
|---|---|
| 나이/성별 | 24 / F |
| 직군 | 프리랜서 콘텐츠 크리에이터 (카페·일상·여행) |
| 디바이스 | iPhone 14 Pro |
| SNS | Instagram 8K 팔로워, TikTok 1.2K |
| 현재 도구 | VSCO 유료, Lightroom Mobile, Halide(가끔) |
| Job-to-be-done | "내 피드의 분위기를 *남과 다르게* 유지하면서 매일 1~2장 올린다" |
| Pain Point | 같은 프리셋이 식상해짐 / 메이커별 차별성 부족 / 새로운 필터 발견 채널 적음 |
| moodit 가치 | 메이커별 큐레이션 + Remix로 *나만의* 분위기 유지 + 친구 사이 공유 |
| 결제 의향 | 월 \$5~10 (현재 VSCO 유료 사용 중) |
| 성공 신호 | D1 재방문, 주 3회 이상 촬영, 1주에 1개 신규 필터 적용 |

### 사용 시나리오
1. 출근길 카페에서 음료 사진 — 마켓 트렌딩에서 "Coffee Mood" 다운로드 → 카메라에 즉시 적용.
2. 주말 여행 사진 정리 — 사진 가져오기로 5장 일괄 후보정 + Before/After 토글.
3. 좋아하는 메이커 팔로우 → 새 필터 출시 알림 → 즐겨찾기 컬렉션에 추가.

## P2 — 필터 메이커 "Alex" (1차)

| 항목 | 내용 |
|---|---|
| 나이/성별 | 29 / M |
| 직군 | 시니어 그래픽 디자이너 (직장 + 사이드 프로젝트) |
| 디바이스 | iPhone 15 Pro + iPad + MacBook |
| 외부 채널 | Gumroad에서 Lightroom 프리셋 ~30개 판매(평균 \$5) |
| Job-to-be-done | "내 컬러그레이딩 감각을 *수익화*하면서 브랜딩한다" |
| Pain Point | 프리셋은 정적이고 GPU 셰이더 표현 부족 / 판매 채널이 분산 / 정산 복잡 |
| moodit 가치 | LUT/파라미터 기반 인터랙티브 필터 + 통합 정산 + 메이커 페이지로 브랜딩 |
| 결제 의향 | 코인 환전 + 60% 메이커 분배 |
| 성공 신호 | 주 1회 이상 업로드, 다운로드 100건 이상 필터 보유, 출금 1회 이상 |

### 사용 시나리오
1. 신규 LUT 5개 일괄 임포트 → 파라미터 슬라이더로 강도/대비 조절 → 검수 제출.
2. 대시보드에서 다운로드 추이 + 평점 확인 → 인기 필터를 카테고리 변경.
3. 5,000 코인 도달 → Stripe Connect로 출금 신청.

## P3 — 캐주얼 사용자 "민준" (1차)

| 항목 | 내용 |
|---|---|
| 나이/성별 | 17 / M |
| 디바이스 | iPhone 13 |
| Job-to-be-done | "친구들과 셀카·스냅을 빠르게 찍고 즉시 공유" |
| Pain Point | 보정 앱이 너무 많아 피곤 / 매번 다른 앱 전환 |
| moodit 가치 | Universal Link 1탭으로 친구 필터 적용 / 무료 필터 풀이 충분 |
| 결제 의향 | 무료 위주, 가끔 ₩1,000 미만 캐주얼 결제 |
| 성공 신호 | 주 1회 이상 셔터, 친구 1명 이상 초대 |

### 사용 시나리오
1. 친구가 카톡으로 보낸 moodit 링크 → 앱 열림 → "이 필터로 카메라 열기".
2. 셀카 한 장 → 공유 시트로 카톡 / IG 스토리.

## 2차 타겟

### B1 — 소규모 브랜드 / 인플루언서 마케팅 에이전시
- 자체 브랜드 필터 배포(예: 카페 체인이 시즌 필터 무료 배포).
- 우선순위: Phase 5 이후, B2B 라이선스 모델 검토.

### B2 — 사진 학원 / 교육자
- 학생 과제용 필터 셋, 컬러그레이딩 교재.
- 우선순위: Phase 6 이후, 메이커 페이지 기능 + 라이선스 옵션 활성 후.

---

## 페르소나 우선순위

| 단계 | 우선 페르소나 | 이유 |
|---|---|---|
| Phase 1~2 | P3 → P1 | 무료 다운로드 + 카메라 라이브 — 진입장벽 낮은 P3가 D1 보호. P1이 입소문 시동. |
| Phase 3 | P2 강화 | 메이커 부족 시 양면 시장 작동 안 함 — 업로드 UX와 메이커 페이지가 핵심. |
| Phase 6 | P1 전환 | 코인/Pro 첫 결제 전환은 P1(이미 VSCO 유료 지불 의향)에서 가장 빠를 가능성. |
