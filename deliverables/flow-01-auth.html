Auth & Onboarding

First-run gate. MooditApp.swift branches on @AppStorage("hasOnboarded") + Firebase Auth state. Guest path lands on Marketplace immediately; authenticated users without a handle get nudged to EditProfileScreen via RootShell.syncHandleOnboarding().

Working

  • Apple-first ordering — Apple Sign In is the top button, matches App Store Review §4.8.
  • Carousel uses @AppStorage("hasOnboarded") — won't re-show after re-install once iCloud KV is enabled.
  • 약관 / 개인정보 SafariView links present.

Gaps

  • "둘러보기" (guest) — copy unclear. Becomes a real anonymous Firebase Auth user but reads like "browsing".
  • Onboarding has 4 pages but no progress dots in the current implementation — only "건너뛰기 / 다음".
  • No tooltip tour on first marketplace landing (proposed).
