Wallet · Paywall · Pro

Coin (1C ≈ ₩14) 충전 → 단일 필터 구매 또는 Pro 구독 (월/연). StoreKit2 + creditCoinsFromIAP / proSubscriptionUpdate / purchaseFilter 콜러블. 환불은 refundRequest. 모든 잔액/가격 표기는 tabular numerals.

Working

  • Coin 잔액 표기 — 마켓 헤더에 항상 노출. 잔액 인지 ↑.
  • 4개 충전 패키지 (100/550/1200/3000) — 가격대별 적정 분포.
  • StoreKit2 영수증 검증 + JWS — 중복 충전 방지 견고.

Gaps

  • 잔액 부족 → 충전 흐름이 modal 위 modal — back stack 혼란 우려.
  • Pro 만료 임박 (7일 이내) banner 가 wallet 화면에 없음.
  • Refund Request reason 이 free-text — picker 형태가 분류/통계에 유리.
