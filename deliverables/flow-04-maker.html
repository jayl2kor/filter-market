Maker Flow · 필터 만들기 → 마켓 공유

메이커가 필터를 만들고 마켓에 올리는 전체 흐름. EditorDraftStore 가 단계별 상태 (parameters / LUT / cover / tags / TOS / pending) 를 관리. uploadInit → R2 PUT → uploadFinalize → submitForReview 콜러블 시퀀스를 SwiftUI workflow 로 wrapping.

Working

  • Step-by-step workflow — Editor → Cover → Tags → TOS → Pending. 각 단계가 별도 화면으로 깔끔히 분리.
  • Long-press before/after on parameter sliders — 직관적.
  • 약관 3종 분리 동의 (원본/정책/상업) — KFTC 권장 형태.

Gaps

  • 업로드 진행 중 앱 종료 시 stuck draft 가 My Filters 에서 회복 불가.
  • LUT 가져오기 → 적용 미리보기 사이의 cube parsing error 처리 부재.
  • Maker Dashboard 가 placeholder. 다운로드/매출 기간 비교 visual 없음.
