# moodit — Flow & Action Gaps Audit

> 버전: v1.0 · 작성일: 2026-05-06 · 상태: Active
>
> 본 문서는 [`PRD.md`](./PRD.md) 사용자 스토리와 [`SCREENS_PLAN.md`](./SCREENS_PLAN.md) 화면 인벤토리를 교차 검증해, **흐름이 끊기거나 액션이 누락된 지점**을 찾아낸 결과다. 우선순위별로 정리하고, 추가 화면이 필요한 항목은 본 라운드에서 보강한다.

---

## 1. 점검 방법

각 핵심 흐름을 처음부터 끝까지 따라가며 다음 질문으로 검증:

1. **출구가 명확한가?** 모든 화면에 다음 단계가 있는가
2. **실패 경로가 있는가?** 정상 외에 빈/오류/타임아웃 처리가 있는가
3. **사용자가 진행 상황을 아는가?** 비동기 작업의 시각/햅틱 피드백
4. **반복 가능한가?** 한 번 실수해도 되돌아올 수 있는가
5. **App Store 심사 차단인가?** 5.1.1(v) 계정 삭제, 환불 안내, 구독 관리 등

## 2. 흐름별 격차

### 2.1 인증 → 첫 촬영 (Onboarding)

| 단계 | 상태 |
|---|---|
| Welcome carousel (01b) → Login (02/02b) → Camera permission priming → Live (03) | ✅ 정상 |
| 첫 촬영 후 결과 안내 → "저장됨"/"공유" → 다음 행동 유도 | ⚠️ 05에 액션은 있지만 **저장 완료 후 갈 곳 없음** |
| 첫 사용자 코치마크 (필터 강도, 좌우 스와이프 등) | ❌ 없음 — 일단 후속 |

### 2.2 마켓 → 다운로드 → 적용

| 단계 | 상태 |
|---|---|
| 마켓 (06) → Detail (07) → Download progress (07b) → After download (07c) | ✅ |
| **다운로드 후 카메라 자동 적용** 동선 | ⚠️ 07c에 "카메라로 적용" 버튼은 있으나 **카메라가 어떻게 진입 즉시 그 필터를 선택하는지** 명시 X |
| **다운로드 실패 / 재시도** | ❌ states-catalog에 일반 에러는 있으나 **다운로드 실패 retry 흐름 없음** |
| **카테고리 페이지** | ❌ 06의 카테고리 칩 클릭 → 카테고리 detail (필터 그리드 + 정렬) 없음 |

### 2.3 메이커 업로드 → 검수 → 게시

| 단계 | 상태 |
|---|---|
| Editor (11/b/c/d) → Upload (12/b/c/d) → Pending (12e) | ✅ |

## 3. 우선순위별 누락 정리

| # | 화면 / 흐름 | 사유 |
|---|---|---|
